# 两天冲刺与三人分工

安排依据：10月24日13:00—18:00省赛，3人；本计划按10月22日下午起步、最初尚未练习的状态设计。当前已有代理示范记录，见08。以下是自学后的可选训练计划，**不表示任何任务已经完成或通过**。时间均为UTC+8。若实际开始晚于15:45，今天的训练块顺延，保留睡眠、交叉验收和明天限时模拟，不用熬夜补每一道题。

省赛的主线是运动控制、定位导航、视觉感知、ROS集成四模块，最后统一仿真和提交。当前要练的是“读题→做配置→看报告→改一项→重新验证”的闭环，**不是14个练习平均用时逐题刷完**。官方未公布四模块细分权重，不能按第三方练习分数硬分正式赛时。

## 三人的主责和替补关系

| 人员 | 首要责任 | 这两天重点 | 替补责任 |
|---|---|---|---|

| C | ROS集成 | 任务14先R1后G1；通过任务10—12理解视觉、TF、抓取、放置和规划依赖 | 能接手A的视觉模块，检查采集→预处理→模型→后处理链及报告 |

替补的目标不是一句“我看过”，而是由替补在原负责人不碰键鼠的情况下独立完成一次检查和局部修改。A同时主责两个模块，因此运动必须尽早保存稳定版本；B和C不能长时间只等A完成视觉，C须主动承担视觉链解释与核对。

**同账号协作口令：** “A进入运动”“A退出运动”“B进入定位”“C进入ROS”。3台电脑可以同账号处理不同模块，**不能两人同时进入同一模块**。交接先退出再通知对方进入；模拟阶段就按这个规则执行。全部人进入同一个模块旁观操作，应使用一台电脑共同观看，不在各自电脑重复进入。

**今天过关标准：** 三人都知道哪里看题、配置、运行和报告；四模块都有主责且至少各形成一份真实运行反馈；C能用状态码指出ROS最早失败环节；A完成源码位置核对；B能从正确地图发起导航；每人都留下可交接版本。未达项进入明早优先队列，不把第三方截图当自己的成绩。

## 从报告找分的工作方法

按“看到什么→说明什么→下一步验证什么”记录，不说笼统的“结果不对”。

| 报告或现象 | 优先动作 |
|---|---|
| 参数/节点结构未完成 | 对照当前要求补空节点、变量、自定义函数、必填指令参数、资源查看；先消除确定缺项 |
| 动作执行错误 | 看观察/动作/奖励/终止条件与题目目标是否一致；必要时查看对应源码，单项修改后重跑 |
| 导航不动或到不了 | 检查初始定位、地图、航点及朝向、代价地图和规划；ROS层另查完成回调 |
| 状态2/5/8/10卡住 | 查vision服务请求、字段、分支及响应，不先改手臂动作 |
| 状态3/6卡住 | 查抓取点云、模型、TF、手臂完成回调和_finish |
| 放错盒子或错误手松爪 | 查字典key、颜色检测、抓放Hand一致性、位姿是否重复TF |
| 仿真完成但报告未更新 | 核对保存、重新仿真、提交上下文与报告时间/版本，不把旧成绩当新结果 |

任务14练习指导书有结构项和R1/G1子任务分，可以用其报告定位练习缺项；这些分值不能扩展成正式比赛四模块权重。正式比赛只按当日显示的真实报告作决策。
